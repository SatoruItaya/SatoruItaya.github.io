Privacy Policy

Last updated: November 21, 2026

Overview

Fitbit Activity Notifier ("the app") is a personal tool used only by its developer. It is not offered to other users.

Data collected

With the user's consent, the app reads the following data from the Google Health API using the scope https://www.googleapis.com/auth/googlehealth.activity_and_fitness.readonly:

  • Daily step counts
  • Exercise records (exercise type, start time and distance)

How data is used

The data is used only to create a weekly activity report, which is sent to the user's own LINE account via the LINE Messaging API.

Data storage

Health data is processed in memory and is not stored. Only the OAuth refresh token is stored, in the user's own AWS account, to access the Google Health API.

Data sharing

The data is not sold or shared with third parties, except for sending the report to the user's own LINE account. The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from Google Account permissions.

Contact

Questions can be submitted via GitHub Issues.
